# Online generator

Use the [FMCW generator demo](https://fmcw-generator-demo.onrender.com/).

This folder contains the web adapter used by the online generator. It shares
the simulation code and interface in `dataset/`. The online service limits file
size and scene count; use the local generator for complete datasets.

After generation, choose **Browse generated dataset** to browse the saved scenes
with Previous/Next or a scene index. The viewer uses your latest generated file;
a new generation replaces it. Files expire after 15 minutes without activity.
